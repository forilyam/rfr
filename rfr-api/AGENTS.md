# rfr-api

- Сохраняй JSON-моки до явного запроса заменить их реальной реализацией. Не добавляй сохранение фото попутно.
- Не меняй уже применённые миграции Flyway; добавляй новые.
- Изменения GraphQL-схемы и классификации ошибок согласуй с хуками и типами фронтенда.
- Не ослабляй авторизацию ради прохождения тестов.
- HTTP 200 не гарантирует успех GraphQL-запроса: проверяй `errors` и `extensions.classification`.
